**권장 개발 방향**


**1. 공통코드 · 권한 · 감사로그 · 재처리 등 P0 기반을 먼저 확정한다. 여기가 흔들리면 전부 재작업이다.**


**2. 조직 · 창고 · 로케이션 → 제품 · SKU → 재고 코어 순서로 구축한다.**


**3. 입고(2차)와 주문 · 할당(3차)을 이어 붙인 뒤 출고 E2E(4차)를 완성한다.**


**4. 인터페이스(5차)까지 끝나면 주문 수신부터 배송완료까지 한 번에 흐른다. 여기가 MVP 완료 시점이다.**


**5. 배송 · 반품과 B2B 판매오더(6차)는 MVP 안정화 후, 분석 · 고도화(7차)는 운영 데이터가 쌓인 뒤 진행한다.**


**6. '개발 취소'로 바꾼 프로그램은 범위에서 빠지며 진행률 모수에서도 제외된다.**
